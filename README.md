# ✒️ SoftInk Poetry

**SoftInk** is a minimalist poetry platform designed to express emotions through words. It is a digital space where poetry, thoughts, and creativity flow freely—soft like ink, deep like emotion.

🔗 Live Site: 

---

## 🌙 About the Project

SoftInk is a poetry website built to showcase:
- Original poems and short verses ✍️  
- Emotional and aesthetic writing 🌸  
- A calm, distraction-free reading experience 📖  
- A creative space for writers and readers alike  

The goal is to create a soft, modern, and expressive platform where words matter more than visuals.

---

## 🛠️ Built With

- Typescript,Javacript,Express and MonogDb

## ✨ Features

- Minimal and aesthetic UI 🎨  
- Responsive design for all devices 📱  
- Poetry-focused layout for easy reading  
- Clean typography for better reading experience  
- Fast and lightweight performance ⚡
